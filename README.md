# ديباناج — النسخة 2.0 (إعادة بناء)

## ما الذي تغيّر جذرياً

### الخادم (server/)
- إعادة هيكلة كاملة من ملف واحد (`index.js`) إلى بنية معيارية:
  `config/` · `middleware/` · `routes/` · `sockets/` · `utils/`
- **مصادقة JWT حقيقية**: كل مسار إدارة محمي بـ `requireAuth` + `requireRole('admin')`.
- **كلمة مرور إدارة مشفّرة (bcrypt)** بدل نص عادي مكتوب في الكود.
- **حد لطلبات OTP** ومحاولات التحقق عبر Redis (يمنع السبام والقوة الغاشمة).
- **فحص `blocked`** فعلياً عند تسجيل الدخول.
- **بث طلبات مستهدف**: فقط للسائقين المعتمدين (`status='approved'`) والقريبين
  جغرافياً (Redis GEO) والمطابقين لنوع المركبة — بدل بث للجميع.
- **تتبع حي فعلي**: `provider:location` يُعاد بثه للعميل صاحب الرحلة النشطة.
- **إنهاء الرحلة من جهة السائق** + خصم عمولة حقيقي من المحفظة وتسجيله في `transactions`.
- **رفع الوثائق محمي**: تحقق من نوع وحجم الصورة قبل الرفع لـ Supabase Storage.
- **مخطط قاعدة بيانات كامل** في `database/schema.sql` (لم يكن موجوداً إطلاقاً سابقاً).
- CORS مقيّد بنطاقات محددة بدل `*`.

### تطبيق الموبايل (mobile/)
- **نظام تصميم عصري** موحّد: ألوان، خطوط (Cairo)، مسافات، مكونات قابلة لإعادة الاستخدام
  (`core/theme`, `core/widgets`).
- **بنية Feature-first**: كل ميزة في مجلدها (`features/auth`, `features/home`...) بدل تكديس
  كل شيء في `screens/`.
- **عميل REST مركزي** (`ApiClient`) يحقن التوكن تلقائياً ويُعيد `Result<T>` بدل استثناءات نصية.
- **عميل Socket.IO موحّد** بمصادقة توكن + إعادة تسجيل تلقائي عند إعادة الاتصال.
- شاشات مُعاد بناؤها بالتصميم الجديد: البداية، تسجيل الدخول، التحقق (OTP)، الرئيسية.

## ما تبقّى (خارطة الطريق)

الشاشات التالية تحتاج إعادة بناء بنفس النمط (نفس المكونات الجاهزة في `core/`)،
ويمكن إكمالها في الجلسات القادمة:
1. تفاصيل الطلب + عروض السائقين + التتبع الحي (تستهلك أحداث Socket الجديدة).
2. لوحة السائق (استقبال الطلبات ضمن `new:request` المُصفّى الجديد + زر إنهاء الرحلة).
3. لوحة الإدارة (تسجيل دخول بالتوكن الجديد + جلب البيانات بهيدر Authorization).
4. الملف الشخصي، السجل، الورشات، الإعدادات.
5. شاشة تقييم فعلية تُرسل التقييم لجدول `ratings` الجديد.

## خطوات الإعداد

### الخادم
```bash
cd server
npm install
cp .env.example .env   # املأ القيم الحقيقية
# نفّذ database/schema.sql في Supabase SQL Editor
# لتوليد هاش كلمة مرور الإدارة:
node -e "console.log(require('bcryptjs').hashSync('كلمة_المرور', 10))"
npm start
```

### تطبيق الموبايل
```bash
cd mobile
flutter pub get
flutter run
```
